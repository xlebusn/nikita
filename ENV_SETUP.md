3. **NEXT_PUBLIC_APP_URL**
   - Для разработки: `http://localhost:3000`
   - Для продакшена: ваш домен на Vercel (например, `https://telegram-export.vercel.app`)

### Как добавить переменные в v0:

1. Откройте боковую панель слева
2. Нажмите на раздел **Vars**
3. Добавьте каждую переменную:
   - Введите имя переменной (например, `YANDEX_CLIENT_ID`)
   - Введите значение
   - Нажмите "Add"

### Важно!

После добавления всех переменных, перезапустите проект для применения изменений.

1. Перейдите на страницу входа
2. Должна появиться кнопка "Войти через Яндекс"
3. Telegram API ключи сохраняются в разделе Настройки дашборда
